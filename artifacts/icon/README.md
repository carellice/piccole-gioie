# Icona Piccole gioie

Creata con il tool integrato **imagegen**, con sfondo trasparente. Il prompt completo è in `imagegen-prompt.txt`.

- `piccole-gioie-icon-source.png`: originale generato, conservato senza modifiche.
- `../../app/src/main/res/drawable-nodpi/ic_launcher_art.png`: copia ridimensionata a 432 × 432 per il livello Android, con trasparenza conservata.
- L’icona adattiva usa il fondo verde bosco `#314F43` e una variante monocromatica per le icone a tema Android.
- Dalla versione 1.2.1 entrambi i livelli dell’illustrazione hanno 12 dp di margine aggiuntivo, senza modificare il PNG originale.

L’illustrazione precedente in `drawable/app_icon.xml` è stata conservata. Il manifest ora utilizza `mipmap/ic_launcher`.
